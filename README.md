# Vovochka.Store — демо интернет-магазина

Статический демо-магазин на HTML/CSS: каталог, корзина, простая админка. Сделан как пример работы для портфолио.

## Живая демонстрация

- Каталог: https://igorzV23.github.io/shop-demo/index.html
- Корзина: https://igorzV23.github.io/shop-demo/cart.html
- Админка: https://igorzV23.github.io/shop-demo/admin.html

## Что внутри

- index.html — каталог товаров, ровная сетка (4/3/2/1 колонки), реальные фотографии товаров
- cart.html — корзина: количество, сумма, оформление заказа
- admin.html — простая админка: список товаров, добавление и удаление
- style.css — стили: акцентные оранжевые кнопки, тёплый фон, цветные тени карточек
